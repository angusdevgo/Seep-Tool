| # | 板块 | 内容 |

| 9 | 防御加固方案 | 真实可用的修复代码 + 优先级路线图 |

## ⚠️ 使用须知

* **偏移会随编译器版本变化**。若您的构建 SHA256 与文档不符，
  请按各文档 §5「定位方法」自行重新定位 —— **这本身就是核心技能**。
* 点位针对**自建样本**，与任何真实产品无关。
* 软件归属对照表**仅引用设计层分析**，不含任何真实产品的偏移或字节。
