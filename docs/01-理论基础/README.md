## 七类缺陷模式速览

| # | 模式 | 关联 CWE | 一句话 |
|:---:|:---|:---|:---|
| 1 | 单点布尔裁决 | `CWE-602` | 一个布尔量决定全部特权 |
| 2 | 硬编码密钥材料 | `CWE-321` | 客户端同时持有生成权与验证权 |
| 3 | 动态库加载顺序缺陷 | `CWE-427` | 不限定路径加载 → 可被劫持 |
| 4 | 可写全局状态变量 | `CWE-602` | 权益判据存放在用户可写位置 |
| 5 | 明文进程间通信 | `CWE-311` | 鉴权结果无认证地传输 |
| 6 | 自研弱校验算法 | `CWE-327` | 自造密码学轮子 |
| 7 | 空值短路校验 (Fail-Open) | `CWE-287` | 凭据缺失被当作「无需校验」 |

> 📖 详细剖析见 [客户端脆弱性模式矩阵](02-客户端脆弱性模式矩阵.md)
